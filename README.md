# Student Management CLI Application

A simple Python-based **Command-Line Interface (CLI)** application for managing student records.

---

## Purpose

The purpose of this project is to create a basic Student Management System using core Python concepts.

The application allows users to:

- Add a student
- View all students
- Search for a student
- Update student information
- Delete a student
- Display individual student details
- Exit the application safely

This project demonstrates practical use of:

- Functions
- Lists
- Dictionaries
- Loops
- Conditional statements
- Input validation
- Exception handling
- CRUD operations

---

## Features

### Add Student
Add a new student by entering:

- Student ID
- Student Name
- Age
- City

### View Students
Display all registered students in a structured table.

### Search Student
Search for a student using:

- Student ID
- Student Name

Name searches are case-insensitive.

### Update Student
Update the existing student's:

- Name
- Age
- City

### Delete Student
Delete a student using their Student ID.

The application asks for confirmation before deletion.

### Display Student Details
Display complete information about a specific student.

### Input Validation
The application validates user input to prevent invalid data.

### Exception Handling
The application handles invalid input and unexpected errors without crashing.
